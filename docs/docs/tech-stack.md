# Tech Stack

## Frontend
- **React Native** : core framework
- **Expo** : tooling, build service (EAS), and dev workflow
- **Expo Router** : file-based navigation
- **NativeWind** : Tailwind-style styling for React Native
- **Metro** : JavaScript bundler
